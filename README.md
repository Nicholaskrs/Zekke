# Golang Project

## Setup project
 - Clone project
 - Run command
    ```
    go mod tidy
    ```

## Run project

 - Go to root folder
 - Run command
    ```
    go run main.go
    ```
- Server will run in based on 


## Environment
- Copy environment from config.env.example
- Rename copied config.env.example into config.env

## Important Notes
- Currently all time are using time.now so it'll based on machine local time.
